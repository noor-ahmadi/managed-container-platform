# Managed Container Platform

A COSMIC-inspired container platform prototype, starting with a local management cluster and two workload clusters. The cluster lifecycle is in place; Fleet enrollment, the C# service interface, and safe releases come next. With PowerShell 7, Docker's Linux engine, [kind 0.33.0](https://github.com/kubernetes-sigs/kind/releases/tag/v0.33.0), and kubectl within one minor of Kubernetes 1.35 on PATH, run `pwsh -File scripts/local.ps1 check`, then `up` to create the clusters or `down` to remove them. State and credentials stay in the ignored `.local/` directory. Run `pwsh -File scripts/test-local.ps1` for the lifecycle check, which creates and removes three clusters.
