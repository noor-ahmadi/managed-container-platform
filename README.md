# Managed Container Platform

A COSMIC-inspired container platform prototype with a local management cluster and two Fleet members. The foundation checks cover staged deployment, workload envelopes, network policy enforcement, and Deployment status mirroring enabled through Fleet's Work API; the C# service interface and application health gates come next. With PowerShell 7, Docker's Linux engine, kind 0.33.0, Helm 3.22.1, and kubectl within one minor of Kubernetes 1.35 on PATH, run `pwsh -File scripts/local.ps1 check`, then `up` to bootstrap Fleet or `down` to remove the project clusters. Local credentials and test evidence stay in the ignored `.local/` directory. Run `pwsh -File scripts/test-local.ps1` for the full check, which creates and removes three clusters.
